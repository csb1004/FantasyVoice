# Voice 원본 헤더 조사

## 호환 리더 재확인 완료

2026-09-19 구현한 libsndfile 기반 목록 생성기로 전체 파일을 재조사했다.
**25,875개 전부 헤더 읽기 성공, 총 약 18.8049시간, 캐릭터 89개**이다.
이전에 읽지 못한 16개는 44.1kHz, stereo, FLOAT WAV였다.
원본 SHA256과 파일별 형식은 `outputs/inventory/inventory.jsonl`,
요약은 `outputs/inventory/summary.json`에 저장했다.
파일럿 후보는 293개이며 아직 실제 ASR을 실행하지 않았다.
다음은 비교를 위한 최초 조사 기록이다. 두 조사 모두 전체 디코딩/청취 검증은 아니다.

조사일: 2026-09-19. 경로: `D:\DATA\Desktop\FantasyVoice\Voice`.
방법: Python 3.11 표준 `wave` 모듈로 WAV 헤더를 읽음. 원본 변경 없음.
전체 오디오 디코딩, 청취, 클리핑/잡음 분석, 중복 분석은 수행하지 않았다.

총 원본 개수만으로 학습에 사용할 수 있는 분량을 판단하지 않는다.

## 읽힌 파일 형식

| Sample rate | Channels | PCM bits | 파일 수 |
|---:|---:|---:|---:|
| 44,100 Hz | 1 | 16 | 25,524 |
| 44,100 Hz | 2 | 16 | 54 |
| 44,100 Hz | 1 | 24 | 270 |
| 48,000 Hz | 1 | 24 | 11 |

최단 파일: `Voice/Jenny_KOR/REC-L316Mon_227-13.wav`.
극단적으로 짧지만 이 조사에서는 삭제하거나 학습 제외 기준을 확정하지 않았다.

읽기 실패 표본에는 다음이 있다.

- `Voice/Adela_KOR/Adela_selected2_1_ko.wav`
- `Voice/Barbara_KOR/Barbara_selected2_1_ko.wav`
- `Voice/Cathy_KOR/Cathy_selected2_1_ko.wav`
- `Voice/Cathy_KOR/Cathy_selected_1_ko.wav`
- `Voice/Chiara_KOR/chiara_selected_1_ko.wav`

위 표본의 오류는 `unknown format: 3`이다. WAVE format tag 3은 IEEE float이며,
Python 3.11 기본 wave 리더가 이를 지원하지 않는 문제와 실제 파일 손상을 구분해야 한다.
호환 디코더로 재확인하기 전 손상 파일로 분류하지 않는다.

## 구현에 반영할 사항

- 헤더 읽기 실패를 곧바로 손상이나 음성 없음으로 간주하지 않는다.
- 원본 형식이 섞여 있으므로 분석기/학습 모델별 요구 형식으로 사본을 만든다.
- 매우 짧은 파일, 비언어 발성, 긴 파일 및 스테레오를 파일럿에 포함한다.
- 캐릭터별 분량 차이가 크므로 분할 및 평가에서 캐릭터별 결과를 확인한다.
- Google Drive 사본은 아직 검사하거나 동기화하지 않았다.
